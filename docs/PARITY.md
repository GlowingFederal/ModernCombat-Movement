# Modern vanilla mechanics specification

Reference: Java Edition **1.21.11**, with separately verified changes through **26.3**. Targets: Forge **1.7.10**, **1.8.9**, **1.12.2**, Java 8. Modern behavior wins on every target. Native code is retained only for equivalent behavior; being present in 1.12.2 is not a parity exemption.

This is a specification and migration matrix, not a declaration of completed gameplay parity. Implementation and verification are recorded separately in STATUS.md. `Native`, `Adapt`, `Backport`, `Integration`, and `Research` describe the required work relative to the unmodified target.

## Evidence and reproducibility

The source investigation uses Mojang's official version manifest, official mappings, and decompiled vanilla implementations. No Combatives source was used. No vanilla source files or complete game archives are redistributed in this repository.

- Official manifests: <https://piston-meta.mojang.com/mc/game/version_manifest_v2.json>.
- 1.21.11 client SHA-1: `ba2df812c2d12e0219c489c4cd9a5e1f0760f5bd`; mappings SHA-1: `031a68bebf55d824f66d6573d8c752f0e1bf232a`. Source inspection used the cached NeoForm **vanilla decompile** output, not NeoForge's patched sources, for the behavioral specification.
- 26.3 client SHA-1: `e877b6a07acd633fb3bb475002175cec036e7b87`. Download verified against the official manifest; selected unobfuscated classes decompiled with Vineflower 1.11.2. A decompiler warning in an unrelated equipment-break switch is not proof of that method's semantics; conclusions here use the successfully reconstructed movement/combat methods.
- Legacy sources: Forge 10.13.4.1614 / stable 12; Forge 11.15.1.2318 / stable 22; Forge 14.23.5.2859 / stable 39. Forge patches and actual method signatures were inspected independently.
- Official release descriptions: [1.21.11](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-11), [26.3](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3). Descriptions locate changes; source establishes formulas and ownership.

Method references below use Mojang names for modern code and MCP names for legacy code. Internal names can change between references. The version adapters explicitly distinguish MCP development names and SRG production names.

## Combat kit content ownership

No biomes, ores, ingots, smithing progression or unrelated acquisition chains are introduced. Native content stays native where equivalent. This mod owns standalone modern combat content; UAB registrations are reused when present, with explicit behavior adapters rather than duplicate items. UAB remains optional. Modern Regen is mandatory on 1.7.10.

## Historical changes and 26.3 comparison

- 1.9 introduced cooldown combat, sweeping, native offhand/shields and changed armor/Strength. 1.7 and 1.8 need those systems; 1.12 needs later differences rather than a downgrade to the 1.9 specification.
- 1.13 added sprint swimming; later updates added collision-driven crawling and changed crouch dimensions. Modern player radial motion cutoff and square-input processing also require inspecting the current implementation, not copying an older swimming backport.
- Later additions include netherite, current resistance behavior, modern effects and blocks, mace and wind charges, and finally 1.21.11 spear components/stages. Their mere presence in UAB is not evidence of 1.21.11 mechanical parity.
- Selected 26.3 `Player.updatePlayerPose`, attack-strength/base scaling, `LivingEntity.travelInWater`, and knockback arithmetic were source-compared. The inspected arithmetic remains the same; the knockback method now accepts additional damage-source/context parameters. This is not an assertion that all combat or all intervening releases are equivalent.
- 26.3 explicitly makes raising a shield take precedence over hoe/shovel tilling/path actions. This verified correction belongs in the interaction migration. Environment-attribute changes, complete item component differences and every fixed bug have not yet been exhaustively compared; keep them marked Research until qualified.

## Competitive reference protocol

PvP HQ is observational reference only. No public authoritative server implementation or reproducible packet/velocity trace was established during initial research. Marketing pages, player anecdotes and protocol version support cannot establish vanilla mechanics or prove a modified knockback formula.

Compare controlled vanilla 1.21.11 and 26.3 fixtures first: same server tick, attack-speed/item data, fall distance, sprint flag, victim grounded state/resistance, pre-hit velocity, hurt immunity and distance/occlusion. Record input tick, accepted hit tick, damage, velocity packet and resulting position. Repeat at fixed latency/jitter, distinguishing arrival order from mechanics. Test sprint cancellation/reset, jump reset, grounded/airborne impacts, hit selection, critical timing, player collision, reach and immunity without introducing automatic techniques or custom profiles.

Public-server testing requires equivalent server configuration and permission for controlled experiments; it has not been performed here. Source-derived numerical tests are useful but are not multiplayer timing or complete gameplay acceptance.
