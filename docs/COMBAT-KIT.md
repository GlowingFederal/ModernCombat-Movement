# Modern combat kit coverage

The scope includes the complete modern combat toolkit, not only netherite. This table separates existing legacy content, implemented additions and pending migration. Presence in UAB is not evidence of modern behavioral parity.

Legacy standalone Mending and Sweeping Edge use reserved, checked IDs; native 1.12 enchantment identities remain registered by Minecraft. Experience repair includes the actual offhand and retains UAB's enable/Baubles settings.

Standalone recipes, brewing and survival acquisition are outside this task's scope. Existing project recipes are retained; no new acquisition chains are fabricated. UAB owns its recipes and progression, with compatibility corrections where needed. New standalone equipment has no ores, ingots, biomes, world generation or unrelated progression dependencies. Content registration is suppressed by UAB presence, while missing behavioral effects can still be supplied by MCM. Removing UAB from an existing world is not an automatic registry migration.

Unknown foreign item attacks and projectiles keep their own implementation. The public item-profile API is explicit opt-in; adapters still have to own the relevant behavior without double damage or velocity processing. See ARCHITECTURE.md.
